    Product

    Order

    • Buyer role: I worked on features for buyers.

  • Floodtir

    BDI Hackathon 2026 · Lat Krabang demo area

    Flood response coordination for Bangkok

    A prototype that connects flood reports, response assignments, and evidence of what was done.

    What it does

    Residents can report flooding with a photo and location through the web or LINE. An official must approve a work order before it goes to the district office. The response team submits evidence before the case can be closed. If the evidence does not confirm that the problem was resolved, the system reopens the work order and keeps a record of each attempt.

    Data pipeline

    1. External sourcesDrainage and water-level records
    2. PostgreSQLStore geospatial data with PostGIS
    3. FastAPIExpose processed data to the dashboard
    4. Interactive mapShow canals, pumps, and monitoring stations

    Water-level readings on the demo map are snapshots, not a live sensor feed.

    My contribution

    I built the pipeline that pulled drainage and water-level data from external APIs, processed and stored it in PostgreSQL, and exposed it through an API. This gave the dashboard the data it needed to display drainage infrastructure and water-level readings as layers on the map.

  • Image Restoration Demo

    Denoising and deblurring with paired image data

    I built a dataset of clean and degraded image pairs to test multiple restoration models and turned the workflow into a Flask demo.

    From unpaired images to reference pairs

    I started with DIV2K images but did not have matching degraded and clean versions for this task. I kept each original as the clean reference and added Gaussian noise to a copy. The degraded copy became the input, and the original became the target for training and evaluation. I also created blur-only and combined noise-and-blur variants.

    Gaussian noise results

    I tested a basic CNN, Residual U-Net, MIRNet-v2, a diffusion model, and two pretrained NAFNet variants. PSNR measures pixel-level reconstruction fidelity in decibels; SSIM measures how closely the restored image preserves the reference image’s structure.

    ModelPSNR (dB)SSIM
    Basic CNN32.780.8904
    Residual U-Net33.010.8978
    MIRNet-v233.110.8988
    Diffusion15.590.5664
    NAFNet (SIDD)29.160.8174
    NAFNet (GoPro)5.190.0205

    These are saved notebook results for noise-only inputs. Evaluation settings may differ between notebooks, so the table is not a controlled ranking. The GoPro weights were trained for motion deblurring, not denoising.

    Flask demo

    Upload an image, adjust the Gaussian noise and blur, then select an available restoration model. The demo shows the original, degraded, and restored images together and reports PSNR and SSIM against the uploaded reference.
